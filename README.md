# 2026kumamotoearthquake (令和８年熊本地震 一次情報リンク集)

令和8年熊本地震に関する、信頼できる一次情報（公的機関や報道機関など）を集約したリンク集です。災害時のデマ拡散を防ぎ、必要な情報へ素早くアクセスできるようにすることを目的としています。

## ⚠️ 免責事項 (Disclaimer)

* 本サイトは有志による非公式のリンク集です。
* 災害の状況変化に伴い、リンク先のURLが変更されたり、アクセスしづらくなる可能性があります。
* 掲載されている情報の正確性・最新性について保証するものではありません。**必ず気象庁や各自治体など、リンク先の公式発表をご自身で確認してください。**

## 🤝 コントリビューション (情報の追加について)

情報の追加・修正の提案を歓迎します。IssueまたはPull Requestにてお知らせください。

**【掲載基準】**
不確かな情報の拡散を防ぐため、当サイトでは以下の情報源のみを掲載対象としています。
* 国・自治体などの公的機関
* インフラ事業者（電力、交通網など）
* 大手報道機関（テレビ局、新聞社など）
* ※個人のSNSアカウントや、真偽が不確かなまとめサイトなどは掲載を見送らせていただきます。

## 💻 開発者向け情報

本プロジェクトは Vite + Vanilla JS/CSS で構築されています。ローカル環境で動かす手順は以下の通りです。

### 動作環境
- Node.js (LTS推奨)

### セットアップ
```bash
# リポジトリのクローン
git clone https://github.com/yasudajs/2026kminfo.git
cd 2026kminfo

# パッケージのインストール
npm install

# 開発用サーバーの起動
npm run dev
```
